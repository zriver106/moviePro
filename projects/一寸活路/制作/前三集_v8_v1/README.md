## 文件

- `导演与连续性.md`：分集口径、阶段造型、空间轴线、钱款与伤势状态。
- `机关与轴线.svg`：明确南梯、北门、绳轮、铜销两次受力及门外三步。物理关系看这张，材质看资产图。
- `镜头设计.tsv`：本轮作者源；对应本目录冻结的 `文字快照/剧本/EP001–003.md` 和 `文字快照/分镜/EP001–003.json`。
- `镜头图修订.json`：单镜视觉复核后的提示词、参考图与版本修订，绑定作者源指纹。
- `分集资产调用表.md`：每项资产在三集中的具体调用镜号。
- `制作标注.json`：与作者源指纹绑定的画面文字、入画范围及首帧提示词标注；源改动后必须复核。
- 本目录 `文字快照/分镜/EPxxx_中文.md/html`：JSON的中文投影，修改JSON后重新生成。
- `资产请求.json`：当前采用的每张资产图及其参考来源；旧修订图留在各资产目录，可追溯。
- `资产/<名称>/cells.json`：实测分隔位置与单格参考；不能用宫格原图直接当一镜的多个人物。
- `逐镜请求.json` 与 `逐镜/`：每镜独立调用Seedream并绑定该镜人物、状态、场景和道具。
- `故事板请求.json` 与 `故事板/`：由单镜图片本地排版，六格一页，左右顺序后再到下一行；14页覆盖84镜。早期直接生成的EP001_P01.jpg串人，已弃用。
- `来源锁.json`：原著、指定v8身份参考、作者源的SHA-256。
- `剧本复核.md`：M3原始FAIL与原著复核裁决；通过force记载预制作内容锁，未伪造PASS。

## 阶段边界

本轮交付用于资产和分镜审阅。彩色宫格是构图故事板，含模型对细部的近似；最终逐镜关键帧须再验左右伤势、可读文字、水位、铜销及绳路，之后才进入视频。机器生成的英文标注是资产板说明，不是剧中道具文字。

角色v8的原图与旧交付清单均未覆盖。新增角色及开篇服装在本制作版本中独立保存。陆照、阿砾先从v8面部参考生成开篇单张母板，再从母板派生多视图；陆照伤势单独做状态板以降低左右侧漂移。
