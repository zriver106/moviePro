# 一寸活路 · 前三集30秒段落制作

当前入口：[项目制作入口](../../制作入口.html)。实际状态：[制作状态](../../制作状态.json)。

## 制作单位

- EP001_A/B、EP002_A/B、EP003_A/B，每段一次30秒API请求；每集预算60秒。
- 原57镜仍是剧情动作索引，不再逐镜提交独立视频。
- 模型：Seedance 2.5 reference-to-video；首轮480p、16:9、原生中文音轨。风格沿用Seedream立体国漫定妆_v8。
- 长镜范围与段内转场详见[30秒方案](30秒分段方案.md)。两个API片段的接缝不宣称为原生超过30秒的一镜到底。

## 门禁与来源

1. 原剧本和文字分镜真实S评级与源文件指纹保持有效。
2. 30秒重排经过小说评级任务独立复评，剧情完整、动作空间与连续性、节奏对白、运镜转场执行四项均S；见[真实外评](分段外评.json)。
3. 冻结方案JSON不因技术状态变更而改写。其逐段旧review_status字段为送审时快照，最终评级以分段外评及证据指纹为准。
4. 图片须在[参考采用](参考采用.json)中有实际视觉检查和文件指纹，按[段落引用](段落引用.json)绑定。
5. 资产ID、路径、技术参数及忠实于原稿的修图不另外送剧情评级。
6. EP001_B、EP003_B须用对应A段实际验收末帧，记录前段视频指纹。

## 实际验收

30秒生成完成后，核验容器时长和原生音轨；抽取逐秒画面及关键动作细帧，回读中文对白，检查身份、手掌药布、左肩伤、道具流转、行动因果与连续摄影。对照动作及对白时间窗，不能把预算时长当作已经演完。问题候选保持停用，返修保留take记录。

## 工具

- `scripts/yichun_video30.py`：preflight/run/asr；同一未完成请求禁止重复付费提交。
- `scripts/yichun_video_qc.py`：生成真实帧接触表、媒体参数与待验收清单；不自动批准内容。
- 图片/视频本体留在本地，上传缓存不入库；请求、指纹与验收记录入库。
