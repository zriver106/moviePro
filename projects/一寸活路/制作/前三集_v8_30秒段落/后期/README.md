# 配乐与中文字幕

音乐源为项目根目录 `kim-bgm/`，6首原文件保留不动。音乐清单记录时长和SHA256。

## 配乐取舍

| 段落 | 音乐进入区间 | 其余时间 |
|---|---|---|
| EP001_A | 不加音乐 | 水声、木响、呼救和对峙对白 |
| EP001_B | 16.5–30秒，救人后轻入 | 推锥、机关、规则句留白 |
| EP002_A | 24–30秒，工钱与包掌 | 封舱、物证、押解留白 |
| EP002_B | 10–30秒，家中 | 收锥和闪回规则留白 |
| EP003_A | 不加音乐 | 长镜打斗保留刀、网、脚步和呼吸 |
| EP003_B | 18–30秒，下午接活 | 擒人、止血与家人叮嘱留白 |

先使用《幻昼5.0》前30秒内的片段。自动语言检查未检测到歌词；这不是人工试听结论。《Life Struggle》前30秒检测到人声，本轮暂不用于对白场景。其他四首保留为备选，没有强行全用。

主音轨目标约−16 LUFS；音乐基准约−34 LUFS，对白期间再降低6dB，进入和退出各约1.2秒淡变。编码前限幅预留余量，导出后测量真峰值，目标≤−1.5 dBTP。听感仍需最终音画联合验收，数值不能代替听审。

## 中文字幕

- `字幕/<段落>/计划/`：六段定稿对白SRT/ASS及画内文字清单，是时间预算，不是最终对时。
- `字幕/<段落>/take_XX/`：对应实际视频SHA256和无文本提示ASR的字幕时间草稿；文案用定稿原文纠正同音转写，时点仍保留校对状态。
- ASS为白字黑边，底部安全区，长句自动分行；“三个月前”“翌日”作为左上角时间字幕。
- 画内木牌、票据、售船纸需要单独跟踪合成；在清单中保留，完成前交付门禁不放行。

## 试听与交付

`试听样片/` 导出可看字幕、可听低音量配乐的候选，画面自带“未通过验收”标记。它们不是成片。正式导出同时要求源视频验收通过、字幕时点确认、画内中文合成确认，且所有指纹一致。

使用 `scripts/yichun_post30.py prepare --segment EP002_B --take 4` 生成实际字幕草稿，`render --segment EP002_B --take 4 --preview` 导出带标记试听。普通render没有绕过验收的选项；源码里preview与交付门禁分开。
