## 文件入口

- `总览.html`：采用资源、逐镜状态、可展开的未采用候选及故事板。
- `资源同步核验.json`：85项/57镜/引用路径/文件指纹和门禁检查。
- `资产衔接计划.json`：全部资源实际映射；approved保持false，不能把参考可用误认为最终批准。
- `图片采用记录.json`、`分镜图片采用记录.json`：分别记录参考与画面采用。
- `视觉检查.json`：具体退回原因与待办。
- `交付审计.json`：image_delivery_ready=false时禁止称完整图片交付。
- `逐镜资源调用.tsv`：每镜全部依赖、实际候选及SHA256。

文字S不等于像素、实际动作时长、配音或成片通过。状态文档为操作记录，不属于新创作文本。

评级范围按Andy最新澄清执行：剧本、分镜及直接改变剧情的内容才送评。历史资源外评记录保留溯源，不再作为全部资源文件的强制门槛。
