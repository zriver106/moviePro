# 设定集 · 人物与招式

漫剧战斗样片。**风格：日式动画（赛璐璐上色，粗描边，硬阴影两档）。**

> **[待验]** 漫剧风格没在我们链路上验过。写实路线的一致性锚点是「脸」，
> 漫剧的一致性风险会搬到「画风」（描边粗细、上色档数、高光形状）。
> 这一部要验的就是这个：画风能不能跨镜锁住。

---

## 零、设计时先服从的两条工程约束

这两条不是创作偏好，是我们链路的物理限制，**设计阶段就得让开**：

1. **不设计身体对身体的接触招式。**
   关键帧是从白底棚拍的单人 sheet 里裁格再合成的。两个人分开出图，
   「抓住手腕」「扭打」「抱摔」需要两只手落在同一个空间坐标上，
   合不出来。
   → 所以全部对抗改成**武器对武器、武器对护盾**：劈在盾上、剑锋削发、
     杖身格挡、光纹碎裂。这些只要求两件**道具**相接，人各自站着。

2. **狂化状态进资产 ID，不进 prompt。**
   `CHR-雷昂-常态` / `CHR-雷昂-狂化H1` / `CHR-雷昂-狂化H2`，
   三个形态**全部从同一张常态母板派生**，不是各画各的。
   写「他狂化了」模型不知道要画什么；换一张图它就知道。

## 一、狂剑士 · 雷昂

### 可指认部件（不写形容词，只写能指认的东西）

**脸与体型**
- 男，30 出头。方下颌，颧骨高而平，**左眉骨到颧骨有一道旧疤，斜向下**
- 肩宽，脖颈粗，握剑时前臂青筋成束
- 身高比艾琳高一个头

**头发**
- 深灰近黑，中长，**发尾到下颌线**，向后拨但不束起
- 额前两缕垂到眉毛，打斗时贴在汗湿的额头上

**装束**
- 无袖皮甲背心，深褐，前襟三条横向皮扣带
- 左肩单侧铁质护肩，边缘有豁口（旧伤留下的）
- 右臂从肩到腕缠深色布条，只露手指
- 下身深灰长裤，膝下绑腿

**巨剑（PROP-断影）**
- 剑身宽度约等于他小臂长度的一半，**剑脊有一道贯穿的直血槽**
- 剑格是两片向下压的方铁，无花纹
- 剑柄缠旧皮，**柄尾缺一块**，露出铁芯

### 狂化的三档形态（形态阶梯）

| 档 | 资产 ID | 可指认的变化 |
|---|---|---|
| 常态 | `CHR-雷昂-常态` | 虹膜深褐，眼白正常 |
| 狂化 H1 | `CHR-雷昂-狂化H1` | **虹膜转赤红**，眼白布血丝；右臂布条下透出黑色纹路，到肘 |
| 狂化 H2 | `CHR-雷昂-狂化H2` | 赤红溢出虹膜、整只眼球泛红；黑纹爬到锁骨；呼气可见白雾 |

**H1、H2 都从常态母板换脸以外的部分派生，脸不动。**
黑纹是「有人借他的手」这条线索的视觉佐证 —— 医生指出过：
暗示了受控却没有任何视觉证据，悬念就变成噪音。

### 招式（全部写成可见的身体动作）

| 招 | 身体动作 | 接触对象 |
|---|---|---|
| **落石** | 双手举剑过顶，直劈而下，落点在对手正前方半步 | 盾 |
| **横断** | 单手侧甩，剑走水平，腰随剑转半圈 | 盾 / 空 |
| **贴地斩** | 屈膝下沉，剑贴地面推出，扬起碎石 | 地面 |
| **抬肘格** | 左小臂横在面前，用护肩迎击 | 杖 |
| **拖剑起手** | 剑尖拖地后撤三步，划出一道火星线 | 地面 |

**没有任何一招落在对方身体上。** 最近的接触是「剑锋削落一缕鬓发」——
那是头发不是身体，且只需要一个前后关系，不需要交叠。

## 二、女法师 · 艾琳

### 可指认部件

**脸与体型**
- 女，28。鹅蛋脸，下颌线清晰，**右眼下有一颗小痣**
- 瘦，肩窄，站姿重心偏后脚

**头发**
- 浅金，**高马尾，束点在后脑偏高处**，尾端到肩胛
- 左侧一缕碎发垂在耳前，始终没别上去

**装束**
- 深蓝立领长袍，**从领口到腰有一列七枚圆形银扣**
- 袖口宽，内衬银灰，抬手结印时翻出来
- 腰间束宽皮带，左侧挂三只小皮囊
- 长袍开衩到膝，内穿深色长裤和短靴

**法杖（PROP-静水）**
- 杖长与她身高相当，**顶端是一个开口的银环，环内悬一颗蓝色棱形晶体**（不接触环身）
- 杖身有三道螺旋刻痕，从顶端旋到握把

### 护盾体系（三层，这是战斗读得懂的关键）

护盾**不是一块板**，是三层同心的六边形光纹，从外到内：

| 层 | 颜色 | 碎掉时的表现 |
|---|---|---|
| 外层 · 光粒 | 浅蓝，半透明 | 碎成细小光点向外飘散 |
| 中层 · 纹 | 深蓝，可见六边形网格线 | 网格从受击点裂开，像玻璃 |
| 内层 · 核 | 银白，几乎不透明 | **裂一道缝就是极限**，不再碎 |

**观众靠数还剩几层就知道打到哪一步了。** 这是把「激烈」变成可读的办法 ——
不靠形容词，靠可数的东西。

### 招式

| 招 | 身体动作 | 效果 |
|---|---|---|
| **横杖** | 双手握杖举至面前，杖身水平 | 硬接一击 |
| **三印** | 左手在胸前连点三下（拇指依次触食指、中指、无名指） | 补一层光纹 |
| **点地** | 杖尖顿地，膝盖微屈，重心下沉 | 后撤后稳住 |
| **推环** | 单手推出杖顶银环，晶体亮起 | 把对手震退半步 |
| **收袖** | 抬臂时宽袖翻落，露出银灰内衬 | 每次结印前的固定前置动作 |

**「收袖」是她的动作签名** —— 每次结印前都出现，观众第二次看到就知道
她要补盾了。签名动作让打斗有节奏，不是一堆乱挥。

## 三、两人的对位关系

打斗要看得懂，靠的是**一攻一守的固定对位**，不是双方乱打：

```
雷昂 落石   →  艾琳 横杖   →  外层碎（光点飘散）
雷昂 横断   →  艾琳 点地后撤 → 剑锋削落她一缕鬓发
艾琳 收袖三印 →  补回一层
雷昂 贴地斩  →  艾琳 推环   →  两力相撞，中层网格裂开
雷昂 落石（H2）→  艾琳 横杖硬接 → 内层裂一道缝，僵住
```

**节奏是「他攻三次，她守两次补一次」**，最后一击两人同时发力，
谁都撤不了 —— 这就是僵局。

## 四、60 秒的时间分配（战斗占 70%）

| 段 | 秒 | 内容 | 占比 |
|---|---|---|---|
| 认出 | 0–6 | 剑压在盾上，两人对视，各喊一声名字 | 10% |
| **第一轮交手** | 6–20 | 落石 → 横杖 → 外层碎；横断 → 后撤 → 削发 | |
| 一句台词 | 20–24 | 他说要带走的东西（**在交手间隙说，不停打**） | |
| **第二轮交手** | 24–38 | 收袖三印补盾；贴地斩 → 推环 → 中层裂 | **70%** |
| 一句台词 | 38–42 | 她说为什么不能让 | |
| **第三轮 · 僵局** | 42–60 | 他狂化到 H2，落石；她横杖硬接；内层裂缝，两人同时发力停住 | |

**战斗 42 秒，对话 18 秒。** 台词三句，全部压在两轮交手的间隙里，
**不为说话停下打斗**。

## 六、把打斗做「帅」的语法：动作三段式

**「帅」不是形容词，是一个可写死的结构。** 每一击都拆成三段，
三段的时长比例决定观感：

```
预备 anticipation   慢，几乎静止   —— 蓄力、重心下沉、剑拖地
爆发 action         极短，一帧到位 —— 只有轨迹和残像，看不清中间过程
余韵 follow-through 短，惯性继续   —— 布料、头发、尘土、光屑还在动
```

**帅感来自三段之间的速度反差**，不是来自动作本身有多花。
预备越静、爆发越短，观感越锐利。写进画面就是：

- 预备帧：人是**静止**的，只有布料和发梢有一点飘
- 爆发帧：**人已经在终点**，中间画残像／速度线／轨迹光，不画过程
- 余韵帧：人定住，**周围的东西还在动**（碎石落地、光屑飘散、发丝回落）

### 漫剧专用的视觉装置（写实风格不能用，漫剧能用）

| 装置 | 什么时候用 | 画面怎么写 |
|---|---|---|
| **残像** | 高速位移 | 同一角色的三重半透明轮廓沿运动方向拉开 |
| **速度线** | 爆发帧 | 背景转成放射状线条，主体保持清晰 |
| **冲击环** | 两力相撞 | 撞击点向外扩散一圈扁平的白色环 |
| **定格** | 大招命中前一瞬 | 全画面静止，只有光屑在动 |
| **轨迹光** | 剑走过的路径 | 一道赤红弧线滞留半秒 |

这些是漫剧比写实**便宜**的地方：用符号代替物理，
一张图就能表达速度，不需要靠帧间连续性去「演」出快。

## 七、大招

### 雷昂 · 断影三重残

| 段 | 秒 | 画面 |
|---|---|---|
| 预备 | 0.6 | 剑尖拖地后撤，**赤红从眼角溢出成两道细线**，黑纹爬满锁骨，呼气成白雾。全身静止 |
| 爆发 | 1.6 | 人从原地消失 → **三重残像沿地面拉开** → 撩剑上挑（第一击）→ 空中转体回劈（第二击）→ 落地贴地斩（第三击）。三击之间不画过渡，只有三道赤红轨迹光并列 |
| 余韵 | 0.6 | 剑尖点地，身后三道火星弧线依次熄灭，碎石继续往下落 |

**视觉签名：三道并列的赤红弧。** 观众看到这三道就知道是他的大招。

### 艾琳 · 静水九环

| 段 | 秒 | 画面 |
|---|---|---|
| 预备 | 0.6 | 双臂同时收袖（平时只收一只），杖竖直立于身前，**晶体从银环里升起悬在头顶** |
| 爆发 | 1.6 | 银环脱离杖顶、悬空放大到与人等高 → **晶体炸成六片绕环旋转** → 六边形光纹从环内连续吐出，一层压一层共九层 |
| 余韵 | 0.6 | 九层同时亮起又同时暗下，只留最内层银白核 |

**视觉签名：六片晶体绕着一个人高的银环旋转。**

### 大招对撞（结尾僵局）

```
三重残的三道轨迹分别撞在九环的三个角度
→ 九层从外往内连续碎（一次碎三层，碎三轮）
→ 只剩内层银白核
→ 剑锋压在核上，核裂一道缝，缝停住
→ 两人同时发力，谁都撤不了
```

**护盾从九层碎到一层，观众是数着看的。** 这就是把「激烈」变成可读的东西。

## 八、重排节奏：42 秒里 16 次交锋

原来每击约 5 秒，太拖。改成**每次交锋 1.5–2.5 秒**：

| 段 | 秒 | 交锋数 | 内容 |
|---|---|---|---|
| 认出 | 0–5 | — | 剑压盾，对视，各喊一声名字 |
| **一轮** | 5–17 | 5 | 落石／横杖・外层碎 → 横断／点地・削发 → 落石／横杖 → 抬肘格 → 推环弹开 |
| 台词① | 17–20 | 1 | 他说话时**剑仍压在盾上**，说完立刻发力 |
| **二轮** | 20–34 | 6 | 收袖三印补盾 → 贴地斩／推环・中层裂 → 连续三劈・网格连碎 → 杖身横扫／抬肘格 |
| 台词② | 34–37 | 1 | 她说话时**正在结印**，手不停 |
| **三轮·大招** | 37–55 | 3 | 他狂化 H2 → 断影三重残 ／ 她静水九环 → 九层碎到一层 |
| 僵局 | 55–60 | — | 剑压在内层核上，裂缝停住，两人同时发力 |

**战斗 42 秒 / 对话 18 秒 = 70% / 30%。**
台词两处都发生在**兵器仍在接触**的时候，不停下打斗。

### 这个节奏为什么和我们的链路同向

- **[实测]** 镜头越长，模型「本该做的事」越少，越会自己往里填东西
  （9.4 秒必造一扇门，缩到 6.6 秒一次通过）。**快节奏 = 短镜头 = 更安全。**
- **[实测]** Seedance 单次生成最短 4 秒。1.5 秒一次交锋**不是一次生成**，
  而是**把 2–3 次交锋放进同一次生成的时间切片里**：
  ```
  0–1.5s   落石劈下，外层光粒碎开
  1.5–3s   横断侧甩，她点地后撤，削落一缕碎发
  3–4.5s   她收袖三印，光纹补回一层
  ```
  一次生成、三次交锋。这正是时间切片存在的意义 ——
  不切片就只能一镜一击，一击 4 秒，节奏必然拖。
