# VFX-贯月光矛

艾琳的贯月光矛，电蓝。分镜 18–20s（银环吸光 → 光矛 → 对撞爆开）。

- id `VFX-贯月光矛` / 类型 vfx / 阵营配色见下

## 这一类资产的通用约定

- **成品是 `cells/<key>.png`（RGBA 透明底）**，不是 `sheet_s1.png`。
  sheet 是黑底 JPEG，只是中间态 —— Seedream 不返回 alpha 通道，
  链路是「黑底出图 → `scripts/vfx_alpha.py` 按亮度抠 → 反预乘成直通 alpha」。
- **合成方式**：直通 alpha，正常叠加即可；要更亮的能量感就走 screen/add。
- **尺度靠画幅比例传递，不靠绝对尺寸。** 孤立在黑底上的特效没有比例参照，
  所以「巨大」写成「从画幅这头到那头」。合成时按大殿宽度缩放。
- 风格串在 `assets.json` 的 `styles.vfx`，**跟角色串是分开的两条** ——
  角色串里有「ornate layered fantasy armour」，拿它出特效会凭空长出一副盔甲。


## 必须有的（逐条可指认）

- 矛体**粗如石柱**，贯穿整个画幅
- 硬白核心 + 电蓝螺旋缠绕在外，后面拖满画幅的尾焰
- `charge`：光流从画幅四面被吸向中心一点，光流拉成长弧
- `clash`：**这一格同时有红和蓝** —— 蓝光矛与赤红剑气正面相撞，
  接触点是过曝白球，一侧饱和电蓝一侧饱和赤红，外加冲击波环和碎屑速度线

## 不属于身份的

- 螺旋的圈数、尾焰长度、吸光光流的条数

## 已知坑

- `clash` 是**唯一一格红蓝同框**的特效。它不属于任何一方的配色体系，
  是「对撞」这个事件本身。别拿它当光矛的普通飞行态用。
- **别把场景几何画进来。** 第一版里剑气带了石柱和石地、光弹带了一把剑刃、
  法阵画在整块石板上、地裂是满幅石板地 —— 这些抠不成 alpha：
  连续的地平面整块跟着进来，叠到真神殿上就是两层地板。
  修法是正面写「悬在空中、四周是空黑」，**不是**写「不要地面」（否定即点名）。
- 碎片、火星、速度线可以留 —— 它们是孤立的，抠得掉，而且是「炸裂感」的来源。
