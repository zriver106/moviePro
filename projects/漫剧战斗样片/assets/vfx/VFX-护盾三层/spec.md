# VFX-护盾三层

艾琳的三层护盾。**这是全片唯一的战况读数**。

- id `VFX-护盾三层` / 类型 vfx / 阵营配色见下

## 这一类资产的通用约定

- **成品是 `cells/<key>.png`（RGBA 透明底）**，不是 `sheet_s1.png`。
  sheet 是黑底 JPEG，只是中间态 —— Seedream 不返回 alpha 通道，
  链路是「黑底出图 → `scripts/vfx_alpha.py` 按亮度抠 → 反预乘成直通 alpha」。
- **合成方式**：直通 alpha，正常叠加即可；要更亮的能量感就走 screen/add。
- **尺度靠画幅比例传递，不靠绝对尺寸。** 孤立在黑底上的特效没有比例参照，
  所以「巨大」写成「从画幅这头到那头」。合成时按大殿宽度缩放。
- 风格串在 `assets.json` 的 `styles.vfx`，**跟角色串是分开的两条** ——
  角色串里有「ornate layered fantasy armour」，拿它出特效会凭空长出一副盔甲。


## 必须有的（逐条可指认）

三层同心，从外到内，**层数是可数的**：

| 层 | 可指认的样子 | 碎掉时 |
|---|---|---|
| 外层 · 光粒 | 一圈细密的电蓝光粒，半透明 | 炸成一片向外飘散的光点云 |
| 中层 · 网 | 深电蓝六边形网格，**每个网眼都有一条硬边线** | 从受击点裂开，裂纹像挡风玻璃一样分叉 |
| 内层 · 核 | 银白实心圆盘，几乎不透明 | **裂一道缝就是极限**，不再碎 |

- 直径要能护住一个站立的人还有余量 —— 不是一块小圆盾
- 爆开态三层齐全：过曝白热核 / 饱和电蓝本体 / 冲击波环 + 碎屑速度线

四格对应分镜的四个读数点：
`intact`(开场) → `outer-burst`(7s 外层碎) → `mesh-crack`(27s 中层全裂) →
`core-fissure`(29s 内层裂缝，僵局)

## 不属于身份的（会变，别锁死）

- 光粒的具体分布、裂纹的走向、网眼的数量
- 整体旋转角度 —— 合成时按机位转

## 已知坑

- **`core-fissure` 是个圆盘不是六边形。** 设定集只写了「银白、裂一道缝」，
  没写形状，模型给的是圆。留着 —— 它跟前三格在颜色和质感上一致，
  而且「最内层换个形状」反而强化了「这是最后一层」的读数。
- **别把场景几何画进来。** 第一版里剑气带了石柱和石地、光弹带了一把剑刃、
  法阵画在整块石板上、地裂是满幅石板地 —— 这些抠不成 alpha：
  连续的地平面整块跟着进来，叠到真神殿上就是两层地板。
  修法是正面写「悬在空中、四周是空黑」，**不是**写「不要地面」（否定即点名）。
- 碎片、火星、速度线可以留 —— 它们是孤立的，抠得掉，而且是「炸裂感」的来源。
