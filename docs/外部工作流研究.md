# 外部工作流研究

三个抖音视频拆出来的方法论。原视频不能直接看，链路是
`yt-dlp --cookies-from-browser chrome` 下载 → `ffmpeg` 抽音轨 → `mlx_whisper` 转文字
→ `ffmpeg` 抽帧 → 逐帧读屏。

**这条链路本身有一条教训**：旁白转出来的文字里**一个可执行参数都没有**。
命名规则、分辨率门禁、时长区间、色卡 hex、文件路径——全在屏幕上，作者一句没念。
第一遍我只听完旁白就写了报告，漏掉的恰好是唯一能抄的部分。
**解说是给人听的层，屏幕是可执行的层，两层内容不重合。**

## 一、阶段划分：剧本和分镜之间还有两层

我们现在是 **剧本 → 分镜 → 出图**。他是：

```
P0A  剧本解析与创作基准     ~10 项，每条标来源档位
P0B  视觉基准               导演方向 / 影视参考 / 摄影系统 / 光线曝光
P2   资产                   角色 → 道具 → 场景（含拓扑图、户型图、色卡）
P3   全片导演地图           U01…U23 镜头单元表
P4   逐单元资产审计         按单元反查它需要哪些资产，逐个过门禁
```

**拿到剧本第一件事不是出提示词，是建台账**（一个版本化的 md，
`惊变72小时-续_制作台账_重跑_1.8.0.md`）。**第三件事才画第一张图，
而那张图是地图，不是场景。**

每两个阶段之间有显式人工卡点：

```
【请确认】以上导演地图及首镜 U01 是否认可？
【确认后下一步】进入 P4，仅审计 U01 需要的 3 名角色、Lily 抱兔状态、
                雪林、兔子道具、树井动态补图与非语言音轨。
```

作者定性：**「资产决定作品上限，提示词只能决定下限」**、
「制作资产这一环节在整个过程中至少占比 50%」、
「盲目追求效率，带来的质量一定不高」。

## 二、三档来源标签（P0A 的核心机制）

P0A 每一条主张都标注它从哪来：

| 标签 | 含义 |
|---|---|
| **剧本事实** | 剧本里白纸黑字写的 |
| **强推断** | 从剧本推出来的（英语对白＋人名＋高山针叶林＋独立木屋 → 北美山区） |
| **导演提案** | 剧本没写，是补的 |

**标签是逐条的，不是逐节的**——一段导演提案内部还会单独标一句
「但职业尚非剧本事实」。

> 对我们：资产 YAML 里没有「这条是剧本写的还是我编的」。
> 8 个角色 `hair_cut: 未定` 覆盖 732 镜，没人分得清那是「剧本没写」
> 还是「忘了填」。加了标签，`未定` 就必须选一档，编不出来。

P0A 已确认的条目：

1. 故事概述与核心主题
2. 类型、题材与写实边界（含暴力尺度：「重心放在重量、疼痛、呼吸和人物关系上，避免游戏化连招」）
3. 国家、地域、年代与技术水平
4. **时间与光线**（见下）
5. 语言、口音与声音文化
6. 现实、超自然与威胁规则
7. **空间／户型**（见下）
8. **人物关系与主要人物小传**（见下）
9–10. 未读到

第 4 项里还带事实核对：「标题中的『72小时』属于项目叙事背景，
本续篇当前剧本本身并未呈现 72 小时跨度」——它主动指出片名和剧本对不上。

## 三、时间轴 = 一串光线状态

P0A 第 4 项原文：

> **剧本事实**：严冬、深夜、没膝积雪，后段风雪增强；故事没有跨越到天亮。
> **导演提案**：主线约从 22:00 持续到次日 03:00，总跨度约 5 小时。光线依次经历：
> - 雪林微弱月光与深黑树影
> - 全屋断电、手电筒昏黄光柱
> - 发电机恢复后的老旧电灯
> - 壁炉形成的短暂暖光安全区
> - 卧室近乎全黑的异变空间
> - 大门开启时灌入的冷雪反光

**时间轴不是时间戳，是一串可渲染的光线状态。** 每一格直接进出图 prompt。

这条时间轴在场景资产里落成**状态版本**：场景清单里 5 条带 `·通电`
（全屋断电 → 发电机恢复是剧情事件），同一个房间按供电状态分别立项。
和角色的 `MUTATION-H1` 是同一个机制——**状态进资产 ID，不进 prompt。**

## 四、空间：用图锁，不用字锁

我们已知 Seedance 有三样 prompt 管不住：空间关系、光位、桌面陈设。
他的解法不是把 prompt 写得更狠，是**在 P0/P2 阶段先画出几何**。

### 室外：拓扑图（场景清单第 1 条，1:1）

第一张图不画任何具体场景。真实地形底图上：

- 节点 A→E：高处坡地雪林 / 树井遗落点 / 林缘下段陡坡 / 林缘坡脚 / 坡顶农舍
- 段距标到米：55 / 110 / 70 / 140，**总距离约 375 米**
- 指北针、等高线（1900/1800/1700）、比例尺、上下坡方向图例

> 「如果没有把这些关系定下来，后面每一张图各画各的，跑出来必然出错。」

有了距离和方位，景别（140 米外农舍在画面里多大）、光位（月亮方位一致）、
动线连贯（A 镜出画左，B 镜必须入画右）全都是推出来的，不是碰运气。

### 室内：户型平面图（场景清单第 5 条「一层毛坯户型骨架」，16:9）

先出无陈设的空间骨架，再派生各房间。

> 「没有这张图，空间关系根本无法保证，人物也必然会在自己家里迷路。」

P0A 第 7 项是它的文字版：「农舍内部以门厅为中心：面向大门时，左通餐厨、
右通客厅；客厅沙发面向三联大窗……最终动作链在门厅—走廊—厨房垭口范围发生。
莉莉停留在厨房垭口内侧，不进入……**户型和镜头轴线共同锁定**。」

### 站位靠画不靠写

自建工具「AI短剧工具箱」，三个标签页：`站位标注` / `九宫格切图` / `图片对比`。

站位标注：载入户型底图 → 每个角色一个彩色圆点 + 朝向箭头 → 长拖画动线虚线
→ 导出 PNG 喂给出图模型。

> 我们知道「爸爸在门厅、妈妈在客厅沙发旁」这种文字模型不听。他不写，他画。
> 这就是我们自己那条**「图赢」**。

### 九宫格解决「怎么保证是同一个房间」

以一张室内图为基准，把房间空间关系在内部推演一遍，
**一次性生成正打／反打／左右侧／特写共九个机位**，再切成九张分镜。
一次生成 = 不可能漂。切图工具支持 4/9/16/25 格。

> 对应我们资产逻辑第 4 条「一个资产只有一张图，多状态排在同一张图里一次生成」，
> 只是他把「状态」换成了「机位」。

## 五、人物小传的字段是可渲染的

三个角色字段完全一致：

| 字段 | 例（卢卡斯 / 艾玛） |
|---|---|
| 年龄区间 | 38—42 岁 / 35—39 岁 |
| 族裔性别 | 白人美国男性 / 白人美国女性 |
| 成长背景 | 在北部山地成长；从军经历或山地设备维修 |
| 关系 | 艾玛的丈夫、莉莉的父亲 |
| 功能定位 | 「家庭的情感稳定器，也是被迫进入战斗的保护者」 |
| 外在目标 / 内在恐惧 | 让家人活到天亮 / 自己成为怪物 |
| 弧线 | 「前半段压住恐惧、保护莉莉……转为持斧反击，高潮中以水果刀介入双兽搏斗」 |
| **身体** | 「长期劳动形成的结实感，而非健美体型」 |
| **造型** | 「保留疲惫、低温和长途奔逃痕迹，**不做无损妆面**」 |
| **服装链** | 冬季外套 → 脱去外套的衬衫 → … |
| **声音** | 「低沉、有疲劳感，压力下习惯缩短句子」/「由颤抖气音转为撕裂」 |
| 硬约束 | 「所有异变阶段必须依赖同一人类母板」 |

四条我们没有：

1. **服装链是角色级的时间线**——我们只有逐镜 `uses.looks`，没人保证连得成一条链
2. **声音有弧线**——不是一个静态参考音色。我们的 TTS 一角色一参考音
3. **「不做无损妆面」是显式反美颜指令**——出图模型默认往精致里画
4. **身体写成对比句**（结实感 vs 健美体型），不是形容词

### 血缘继承链

四个角色，先只出爸爸和妈妈——**女儿和父母有血缘，必须先确定父母长什么样
再生成女儿**；狼人是男主的爸爸，所以狼人外观基于男主形象设定。
每次继承内部跑一遍垫图。这是人物一致性好的原因。

形态阶梯：`CHR-LUCAS-SHEET-01` → `CHR-LUCAS-MUTATION-H1-SHEET-01`
→ … → `CHR-WEREWOLF-H3-01`。H 是变异阶段编号。

## 六、情绪曲线（作者称「整个分析里最值钱的一项」）

《惊变72小时-续》全片情绪曲线：

- Y 轴 0（平静）→ 4（不安）→ 10（窒息）
- X 轴七幕：逃亡 / 喘息 / 袭击 / 异变 / 失控 / 高潮 / 尾声
- 曲线按功能分段配色：**建立 / 收紧 / 升级 / 窒息 / 释放 / 余震**
- 14 个拍点各带名字和数值：

```
1 雪林奔逃 7.0   2 兔落树井 8.1   3 农舍在望 5.6   4 门外重撞 8.9
5 砸门止息 6.4   6 灯火喘息 3.8   7 黑影听门 6.8   8 地板破袭 9.2
9 荧光告白 5.2  10 异变失控 8.8  11 人性迟疑 9.1  12 双兽血战 9.8
13 纹身真相 10.0  14 黑屏余震 8.6
```

图下三行派生结论：

```
呼吸区：6. 灯火喘息
BGM 重点：2 / 4 / 8 / 9 / 11 / 13
全片原则：每次安全感都只为下一次失控蓄压，真相在胜利瞬间反噬。
```

两个用途，作者明说：一是给创作者看结构，**更重要的是给模型看**——
必须先完成这些拆解，才能为后续出更精准的提示词做上下文准备。

> 对我们：只有 `target_seconds` / `hook_at`，没有幕结构、没有拍点数值。
> BGM 落点和呼吸区现在靠拍脑袋，有曲线就是算出来的。

## 七、P3 全片导演地图 = 时间轴 + 转场策略

U01–U23，每个单元 6~30 秒。**时长写成区间，不是定值。**

| 编号 | 内容 | 时长 | 策略 |
|---|---|---|---|
| U01 | 雪林奔逃，Lily 摔倒、兔子落地 | 10~12秒 | 全新／L2 |
| U02 | Lucas 折返抱起 Lily，被迫放弃兔子 | 14~18秒 | **延长优先**／L2 |
| U03 | 坡脚喘息，发现坡顶农舍 | 14~16秒 | 全新／L1 |
| U09 | 合闸、启动发电机、灯光亮起 | 10~14秒 | 全新／L1 |
| U13 | 地板破袭、拖拽、Emma 挥斧救人 | 26~30秒 | 全新／L2 |
| U19 | 父亲冲入，Emma 取水果刀削肩 | 24~28秒 | **延长优先**／L2 |
| U21 | 后翻摔地、翻滚、Lucas 咬颈反杀 | 18~22秒 | **延长优先**／L2 |
| U23 | 黑屏与演职员字幕 | 8~12秒 | **后期合成** |

**「策略」列就是转场模型**：

- `全新` —— 新起一镜，和上一单元之间有切点
- `延长优先` —— 用平台的「视频延长」接上一单元末帧，无切点连续。
  只出现在 U02 / U19 / U21，三处都是紧接前一单元的同一个动作的延续
- `后期合成` —— 不用模型生成

`L1 / L2` 是复杂度分级（推断：L2 = 多人／大位移／多拍点，L1 = 静态或单拍点）。

> **这就是「分镜有没有考虑时间轴和转场」的答案，而且答案不在分镜层。**
> 单元 6~30 秒也和我们几秒一镜完全不是一个粒度。

## 八、视觉基准锁死（P0B）

1. **总体导演方向**——一句话：「北境雪夜困兽」
2. **影视参考**——主参《猎凶风河谷》、补参《小丑》，
   并明确写**借鉴什么、不借鉴什么**（「不借鉴其宗教符号或剧情设计」）
3. **摄影系统锁定**——ARRI Alexa 35 + Cooke Panchro/i Classic 球面定焦、
   2.39:1、24fps、180 度快门、克制的胶片印片模拟。
   **镜头家族每个焦段负责什么写死**：
   - 24–32mm 承担雪林逃亡、农舍空间关系和身体搏斗
   - 40–50mm 承担家庭关系与日常观察
   - 75mm 只用于莉莉告白、卢卡斯人性迟疑和纹身揭示等心理节点
4. **光线与曝光**——整体欠曝约 0.7–1 档；
   **高光以雪面、白色羽绒服、额头皮肤和金属刀面不过曝为准**

每条后面跟一条禁令：禁止无动机推移、禁止无人机式室内穿行、禁止游戏化过肩镜头、
禁止无来源轮廓光、禁止明亮蓝调夜景／发光黑位／HDR。

> **注意边界**：这些禁令写在**给人看的基准文档**里，不等于能原样进出图 prompt。
> 我们验过「否定即点名」——强先验行为（切镜、门）一点名就爆，
> 弱先验（推镜）才压得住。要搬进 prompt 得逐条过筛。

## 九、资产门禁按类别分

**道具**（`assets/props/P2-关键道具资产批次_1.4.6_最终提示词.md`）硬规则：

```
3:4 竖构图、单件完整入画、浅灰无缝影棚背景、无三视图与说明文字
落盘尺寸严格 1536×2048
```

**角色 sheet** 恰恰相反：横构图、有三视图（正面／背面／大头像）、
图里烧进说明文字（`Emma / Height: 169 cm / Character: Decisive, Protective`）、
浅灰无缝影棚背景。大头像占近一半画幅——和我们测出的
「近景里脸占画面大，参考图里脸也大，五官细节传得更足」是同一个道理。

**门禁查的不只是尺寸，还有语义**：
「军表的 3 点位表冠和无文字时标正确」。

**断点续跑靠核对磁盘**：

> 「我按『当前磁盘上的最新版』重新开始，并先核对刚才中断时是否已有**合格**图片落盘，
> 避免重复消耗。」

判据是**合格**不是**存在**——落盘但没过门禁的不算数。
我们踩过反面：`--skip-existing` 只查 `kf-last` 存不存在。

**道具只留重复出现的**，只出现一次的自动排除。

命名：`SCN-<INT|EXT>-<地点>-<状态>-<序号>_<用途>_<版本>`。
INT/EXT 是影视工业标准前缀。

三条：

- **`_candidate` 后缀是状态机**——候选和已确认在文件名上就分开
- **每个文件名带版本号**，改产物换版本不覆盖：
  「原合并色卡暂时保留，确认后才会由这两张正式替代。台账校验通过。」
  （我们吃过亏：删过对方正在渲的 24 张关键帧）
- **skill 会把工具脚本写进项目**（`tools/build_split_environment_color_cards_1_9_3.py`），
  版本号跟着走。色卡因此是脚本算出来的确定 hex，不是模型画的

**画幅按场景类型分配**：地图 1:1、外景 21:9、内景 16:9。

**色卡**：室内外各一套，2048×1152，六格带 hex。
标题双语：「惊变72小时 - 续｜通电农舍室内环境色彩参考 /
POWERED FARMHOUSE INTERIOR COLOR REFERENCE」。
用途是「为后面视频环节的光影和色调不飘移保驾护航」。

## 十一、Seedance 2.5 的 prompt 写法（视频 C）

**核心**：2.5 已具备时序叙事能力，看重空间叙事＋时间叙事，
堆词已行不通。要把剧情拆成**带时间戳的分镜脚本**，一次生成一整段。

反例（旧写法）：

```
雨夜古庭院，黑衣刺客与黑衣锦衣卫激烈交手的视频片段，剑光闪烁，
打斗凌厉，镜头富有电影感。
```

→ 镜头随意切换，打斗动作没有前后逻辑。

正写法，每个时间切片承载**独立的镜头目标**。四个要素：
**景别 / 环境 / 主体 / 光影**（＋运镜＋目的）。

```
0–3秒，全景平移镜头，雨夜古风庭院，青石板布满积水，雨点不断落下，黑衣刺客与
黑衣锦衣卫分别从画面两端入画对峙，四周灯笼随风晃动。室外夜景，冷青暗调，微弱
灯笼暖光形成对比，画面充满肃杀的对峙氛围。

3–6秒，镜头推进至中景，黑衣锦衣卫率先快步冲锋，抽出短刀向前突袭，黑衣刺客迅速
拔剑横挡，刀剑相撞迸出明亮火花，雨水被兵器碰撞激起水雾。

6–10秒，近景持续跟拍二人缠斗，不断辗转移位，黑衣刺客灵巧闪避突袭，顺势挥剑反击，
头发在风雨中飘动，地面积水被脚步踩出涟漪。

10–12秒，镜头向后拉远并上移至鸟瞰俯视，两人交手拉开距离，黑衣锦衣卫旋身挥出强力
斩击，震退黑衣刺客，两人分立庭院两端，雨夜笼罩全场，留下张力十足的收尾画面。
```

每段的目的：建立空间感 → 切入剧情 → 强化动作 → 收尾留悬念。

**光影只在第一段写，后面继承不重复**——和我们「别拿字去重复图已经说过的事」一致。

### 铁律：写具象肢体动作，不写情绪

> ❌「锦衣卫凶狠，刺客冷静」——AI 读不懂抽象情绪
> ✅「锦衣卫率先快步冲锋，抽刀向前突袭，刺客灵巧闪避，顺势挥剑反击」
>
> **情绪在视频生成里是靠动作烘托的，不是靠文字概括。**

和我们 CLAUDE.md「喂给出图模型的动作描述必须是可见的」「内心活动改成可见的
身体信号」完全同源——不同作者、不同模型，独立撞出同一条。

### 二次优化：先出一版，再补密度

不要一开始就写满。先生成，看哪里不够，再针对性加三类东西：
**环境动态 / 肢体细节 / 物理反馈**。

| 原版 | 优化版 |
|---|---|
| 雨点不断落下 | 雨点**持续坠落，溅起细小水花** |
| 四周灯笼随风晃动 | 灯笼**火光摇曳，地面倒映人影** |
| —— | 锦衣卫**衣袂被冷风微微吹动** |
| 雨水被兵器碰撞激起水雾 | ＋**飞溅的雨水被剑光瞬间蒸发** |
| 近景持续跟拍 | 近景**动态**跟拍 |
| —— | ＋**两人头发、衣摆被狂风与剑气吹动，脚下积水四处飞溅** |
| 锦衣卫旋身挥出强力斩击，震退黑衣刺客 | ＋**剑气冲击**震退，**地面雨水向外扩散** |

作者结论：掌握这套能大幅降低**人物崩坏、镜头飘移、剧情断层**的概率。

### 平台侧

即梦（Dreamina）里 Seedance 2.5，12 秒／720P 一次出。后处理菜单：
智能超清 / **视频延长** / 视频编辑 / 补帧 / AI音效 / 对口型 / AI配乐 /
用作参考视频。

**「视频延长」就是 P3 里「延长优先」用的平台能力**——两个视频对上了。

## 十二、和我们现状的差距

| 他有 | 我们 |
|---|---|
| P0A 剧本解析与创作基准（~10 项） | 无。剧本直接跳分镜 |
| 三档来源标签，逐条 | 无。分不清「没写」和「忘填」 |
| 光线时间轴（22:00→03:00 六段） | 无。只有播放时长 |
| 情绪曲线（七幕 14 拍点带数值） | 只有 `target_seconds` / `hook_at` |
| 室外拓扑图（带距离方位等高线） | 无 |
| 室内户型图 + 站位朝向动线标注 | 只有一句 `location.desc` |
| 九宫格一次出全机位 | 逐镜各自生成 |
| 环境色卡（脚本算，带 hex） | 无 |
| 摄影系统全片级锁死（焦段分工） | 只有逐镜 `camera.*` |
| 角色血缘继承链 + 形态阶梯 | 各生成各的 |
| 服装链 / 声音弧线 / 反美颜指令 | 无 |
| P3 单元表：时长区间 + 转场策略列 | `continuity_out` 只是交接说明，无策略、无校验 |
| 资产门禁按类别分，查语义不只查尺寸 | 只查存在性 |
| 文件名带版本，`_candidate` 状态机 | 靠 `--version` 手动传 |
| 阶段间显式人工确认卡点 | 一路跑到底 |

**顺序上最该抄的一条**：先建台账 → 拆十项创作基准 → 画地图 → 才画场景。
和我们自己踩出来的「上游能压住的，视频侧压不住」是同一句话。
