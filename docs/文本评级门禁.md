# 文本评级与出图门禁

## 长期适用范围

Andy指定参考两个本地任务：“按S+标准改编重新&&剧本&&分镜”（`01a07cff-e6fc-7422-9d7b-1741b6d7c819`）与“小说评级”（`01a08ea0-8c4d-74e0-ae4b-95fa647cfb4d`）。已核对其真实返修、复评和冻结稿确认记录。

评级只针对剧本、文字分镜及直接关联剧情的内容变更，例如情节、对白、人物动机、因果、动作顺序、剧情所需伤势与道具连续性。产出者先自查，再独立评级；低于S返修并真实复评，达标才定稿。已经通过且未改变的剧情不重复送评。

资产ID、文件名、目录路径、资源索引、调用表、状态记录、格式整理、技术参数不需要剧情评级。忠实落实已评级内容的资产说明、生成提示词和图片纠偏，只做制作一致性检查与视觉检查；其中若提出剧情变更，先同步回剧本/分镜并复评。是否送评取决于实际是否改变剧情，不按“凡是文字”或文件类型判断。

历史资源送审记录保留溯源，不作为未来资产管理字段或技术调整的强制门槛。

## 流程

1. 明确每集预算、改编范围和指定造型。本项目以约一分钟为目标，当前三集剪辑预算均60秒；禁止先做126秒再等图片做完才发现偏离。
2. 完成剧本、分镜JSON，生成中文投影；文字阶段允许迭代，不生成角色、场景、道具、白模、彩色分镜或关键帧。
3. 将本版全文与SHA256清单送到本地任务“小说评级”（`01a08ea0-8c4d-74e0-ae4b-95fa647cfb4d`）。读取真实反馈，剧本和文字分镜分别评级。只整理送审包不等于已送达，只发送不等于通过。
4. 低于S的适用维度按“镜号/原句→问题→影响→最小修改→复核标准”返修，同源问题合并；成熟内容保留。更新JSON后同步中文投影、台词声源和跨集状态。
5. 返回评级任务真实复核，取得当前指纹对应的S或以上。不能平均抵消低分，不能为了达标调分；没有实质问题则关闭，不强加新冲突。
6. 保存真实回复、审阅范围、送审清单和分集等级，通过`rating_gate.py`再定稿。更新资产调用计划及状态需求，才进入图片制作；任何图片还须独立视觉检查。

## 评级口径

“小说评级”原始十一维是情绪、人物、战斗、逻辑、世界观、长线追更、财富经营、反派体系、无限能力、爽点、节奏，每项S为小说验收门槛，S+是更突出表现，没有客观百分制换算。小说历史评级不能替代改编审阅。

对一分钟剧本与文字分镜，该任务实际另评开场钩子、人物对白、能力、本集回报、节奏时长、动作空间、分镜执行和一致性等适用维度，分别给剧本/文字分镜结论。不要求每个单集承担整部长篇所有功能，不以还没拍成片给文字扣分。60秒字段、临时语音测长、实际动作可演性是不同证据，不能相互冒充。

首次完整读取实际送审文本；后续小修可以沿用完整审阅基线、核对差异并重读前后文。必须明确真实范围，不把局部复核称为全文精读。已解决问题不无故重开。

## 门禁资料与代码

- `评审/评级规则.json`：评级任务ID、最低等级、每集目标秒数及容差。
- `评审/当前评级.json`：真实外评回复标识与证据指纹、送审清单指纹、逐集两项等级和未解决问题。
- 冻结送审目录：九份源文件、汇编全文、SHA256清单、真实历次评语。主目录文件有任何改动便过期，不能靠旧快照维持通过。
- `scripts/rating_gate.py`：缺失、损坏、范围为空、低分、问题未清、指纹不符、预算不符均拒绝。一次报告全部可检查的问题。
- `gen_asset`、`gen_kf`（含空场底板）、`gen_kf_chain`、`gen_whitemodel`的实际生成入口已接闸；dry-run仍只做文本准备。新增付费入口必须先调用此闸，禁止直接调用供应商逃过项目评级。
- `script_lock.require`也检查独立评级；历史force锁不能放行。`script_lock --force`已停用，真实外评用`--external-review`，旧M3判断保留为历史诊断。
- `yichun_prepro.py`专属84镜旧版的出图函数和批量入口永久停用，保留检查及归档功能。历史图片只能逐项重新验证，不沿用旧镜号覆盖新镜头。

## 本次已发生的纠正

旧版未通过评级仍通过force出图，是流程错误。旧第一集126.7秒，真实评级为剧本A-、分镜B。后续经过真实返修和复评，最新22/17/18镜稿逐集S/S。首次纠正阶段只更新文本、状态、计划和门禁，未出图。早期46张资产板与84张单镜图保留历史；可用性需按新稿重验，不能把“已生成”标成“已验收”。

## 后续资源同步与图片检查

`yichun_resources.py`保留当前剧本与分镜评级、资源所属正文版本、参考图采用与图片指纹检查，取消整份资源规格/绑定文件必须独立外评和逐字哈希相等的附加限制。改资产ID、路径或技术参数不会触发剧情复评。已被视觉检查退回的原始镜头改走纠错任务；忠实恢复已定稿画面无需另送文字评级。若纠错实际改变剧情，必须先改剧本/分镜并独立复评，资源不能反向绕过正文门禁。

新版85项资源与57镜绑定已同步。当前40镜候选中仅10镜内部采用，图片未全部完成；27镜退回、3镜待细查，17镜未生成。铜片穿孔和绳轮连接仍被视觉门禁拦截。最新实际状态以项目`制作状态.json`、`资源同步核验.json`和`视觉检查.json`为准，不能以已评级文本或生成数量宣称完整画面交付。
