# 白模故事板 —— 资产和关键帧之间缺的那一道

2026-08-17。来源：N次方Ai（华小二团队）两条抖音视频，
「十种手绘故事板」和「POV视角采访八仙短片制作方法」。

Andy 一句话点破了两者的关系：**白模实际上是上一个视频里线稿的角色** ——
同一个位置（控制图），换了一种画法。

---

## 一、它解决什么

我们文档里记着一条硬伤：**Seedance / Seedream 的 prompt 管不住空间关系**
（说了「椅子在桌子对面」，它放在人身后同侧）、光位、桌面陈设。

chaoge 那套用「户型图 + 手工站位标注工具」解决 —— **手工每镜点，100 集扛不住**。
这套用一张**模型自己生成的控制图**解决，可自动化。

---

## 二、先记一个坑：带标注箭头的手绘板不能直接当控制图

第一条视频教的是**手绘线稿故事板**，每格带三行标注（镜头/表演/音效）
和彩色箭头（红=机位运动、蓝=角色轨迹、绿=互动、橙=冲击、紫=音效）。

**第二条视频开头就说这套有一个致命缺点**：

> 生成视频后，总是有出现标注箭头的几率，即使加限制词也有中招的时候，
> 重新生成需要花米。

**标注被模型当成画面内容画进成片里。** 这正是我们的语域铁律换了个位置：
之前是「给人看的文字不能直接喂模型」，这次是**「给人看的标注不能直接进控制图」**。

我差点就掉进去 —— 看完第一条视频我给 Andy 的建议就是「用调度分镜故事板
（五色箭头那种）当控制图」。第二条视频把这条否掉了。

**规律：控制图上的每一样东西，模型都可能照着画。**

---

## 三、白模故事板怎么避开

不画箭头，改用**本来就属于画面的白色中性标记**表达运动：

```
短拖影 · 接触爆点 · 地面擦痕 · 尘土环 · 水波飞溅 · 撞击碎屑 · 冲击波环
```

即使这些渲进成片，看起来是动态模糊和扬尘，**不是 UI 箭头**。
这是它比手绘板高明的地方：**把标注做成 diegetic 的**。

---

## 四、版面

```
左侧大图块   P00 俯视布局图：人物在场景中的站位与运镜
右侧小图块   P01…P0N 逐镜取景框：镜头 / 景别 / 人物特征 / 动作
```

每格标题格式 `P## /shot tag /beat name`，带时间码，例：

```
P01  /00:00.0-00:01.8  /特写  /眼冲近照
P02  /00:01.8-00:04.2  /中景  /…
```

两个规格，按成片时长选：

| 模板 | 格数 | 适配 |
|---|---|---|
| 九视图 | 3×3 | 15 秒视频 |
| 四视图 | 2×2 | 8 秒视频 |

## 五、提示词模板的四个模块（实测原文要点）

**[创建]** 一句话说清这一板要传达什么 ——
「通过镜头角度、景别、姿态、画面方向和空间地理关系，传达空间压迫、
动作接触点、力量转移、撞击来源、借力反制和最终控场结果」。
末尾一句：**不要把方括号标题模块渲染成画面文字。**

**[HEADER]** 顶部标题区，细线分隔，**图形处理只能出现在分镜格之外**。
标题区只允许出现指定的那两行文字。

**[BOARD]** 严格网格：3 列 ×3 行，按 `P##` 从左到右、从上到下填满；
**每格严格 16:9（宽是高的 1.78 倍），全部 9 格比例和大小完全一致**；
不添加空白格、不添加额外分镜。每个 BEATS 条目只对应一个分镜格。

**[STYLE]** 明亮黏土模型 3D 预演故事板，未贴图块面模型、哑光浅陶土材质，
仅柔和白色 / 浅暖灰 / 少量中性灰。
**画面是电影动作预演，不是成片，不是插画，不是精雕塑成品。**
角色保留清晰剪影、身体比例、发型轮廓、服装体积和动作姿态，表面简洁光滑。

> **注意这份模板里全是否定词**（不能/不允许/不要），跟我们「否定即点名」
> 看似冲突。按我们自己收窄过的版本解释得通：**否定同时点名和压制，
> 判据是那个行为是不是模型本来就想做的。** STYLE 已经把画风钉成白模之后，
> 「画彩色皮肤纹理」变成弱先验，点名就是禁止。
> 这跟「空镜加负向词『人影』之后人真的消失」是同一类。

## 六、完整流程

```
1  分镜内容（我们已有的 JSON/文字）
2  喂给 LLM，三大模块拼提示词：
     ① 具体要求：「请将我的分镜内容融合到下面的白模故事板模板中，
        注意只是融合，不改变原分镜的内容，融合后也不能出现原模板中的内容」
     ② 分镜内容
     ③ 白模故事板模板
   → 得到贴合本集分镜的白模故事板提示词
3  该提示词 + 人物图片 → 出白模故事板图片
4  白模故事板图片 + 人物图片 → 视频节点 + 运镜提示词 → 分镜视频
```

**第 2 步那句「融合后也不能出现原模板中的内容」很关键** ——
否则模板里的示例（地下停车场、女保镖）会漏进产出。
这跟我们踩过的「派生字段没跟着源字段更新」是同一类：模板残留。

---

## 七、和我们现有链路的关系

| 它的东西 | 我们对应的 | 差距 |
|---|---|---|
| 3D白模角色转面 | `char sheet`（24 格） | **已有**，我们的更细 |
| 场景固定故事板（平面户型图） | 无 | **缺** —— chaoge 也强调这一张 |
| 白模故事板（P00 布局 + P01…逐镜） | 无 | **缺，这是要加的那一道** |
| 每格 `镜头/表演/音效` | `camera` / `action` / `sound` | 字段一一对应，转换直接 |
| 九视图/四视图按时长选 | `beats_en` 时间切片 | 概念相同，它是图形版 |

**插的位置**：

```
资产 →【白模故事板】→ 人审站位 → 关键帧 → 视频
          ↑ 便宜、可迭代、错了重出一张就行
```

**最值钱的是便宜。** 站位错了，在白模板上改一次几分钱；
在成品关键帧上改要重出整张；到成片才发现要重渲。
**把「空间关系对不对」这个判断挪到最便宜的那一层。**

## 八、要先验的两件事（都没验，标 [待验]）

1. **[待验] 白模故事板 + 我们已有的角色定妆图同时喂，会不会打架。**
   他的流程里是「白模板 + 人物图片」两张一起喂，但我们的角色资产
   带着完整的黑金/红黑重铠和红发，白模板是无贴图块面 ——
   **两张图在「这个人长什么样」上直接冲突**。
   按我们自己那条「图赢」，两张图冲突时谁赢没验过。
   **先拿一镜做对照实验，别直接上全片。**

2. **[待验] 白模的块面质感会不会渗进成片。**
   模板里反复强调「不是成片、不是插画」，说明模型确实有把预演质感
   带进输出的倾向。我们的成片是高精度 CG，一旦渗进来就是灾难。
