# 打斗分镜

写打戏分镜的规则。判据和数字都是实测的，直接照用。

---

## 一、先配牌面，再排节奏

**打不激烈，九成是双方手里的牌不对等，不是剪辑问题。**

```
只有一方能远程   →  另一方只能追，攻防退化成追逐
只有一方能近战   →  贴上来就赢，攻防退化成抢身位
双方都有远程+近战 →  谁都不能靠站位赢，只能靠出招赢
```

**规则：动笔之前先列两张表 —— 每个角色各有几种远程手段、几种近战手段。**
缺一边就先补设定，别进分镜。

参考量级：一方补齐远程手段后，同样时长同样剪法，接触次数从 8 涨到 97。

## 二、把「激烈」变成可数的量

观众判断战况靠可数的东西，不靠形容词。**每场打戏至少要设计两条可读的量**：

**资源读数** —— 有限的、会消耗的东西，每消耗一档观众就知道进度：

```
护盾三层   外层碎成光点 → 中层网格裂如玻璃 → 内层裂一道缝（不再碎）
```

**距离曲线** —— 双方间距要有形状，每次变化由一个**具体招式**造成：

```
远 → 冲到中距 → 交手 → 被震退回远距 → 顶着压制再冲 → 贴身连招 → 僵持
```

**规则：两条量都要在分镜里写死时刻**（第几秒碎哪一层、第几秒距离变化），
不写死模型不会自己安排节奏。

## 三、密度：一条描述带次数，不靠切碎

目标密度 3 次接触/秒。**不能写 90 条指令**（见第四条）。

```
✗  九条指令，每条一次挥砍
✓  「十二连斩：十二道红弧在光纹上连续炸开，连成一条不断的爆闪链」
   —— 一条描述、十二次命中，中间帧由模型补
```

**大数字要挂在具体物件上**：12 发弹、12 根冰棱、12 道弧。
写「密集的攻击」出不来密度。

## 四、运镜：切镜数由「运镜指令条数」决定

**模型按运镜指令的条数理解镜头数，不按时间切片数。**
每写一句 `the camera whips / pushes in / swings`，它就当成一个新镜头。

实测（`check_cuts.py`，打戏阈值 0.4）：

| 写法 | 切点 |
|---|---|
| 9 个切片，每片一条运镜（设计就是要切） | 4 |
| 25 个切片，每片各带一条运镜指令 | 10 |
| 7 个切片，每片一条连贯运动路径 | **0** |

### 规则：动作按秒拆，运镜按段说

要同时满足「逐秒颗粒度」和「一镜到底」：

```
30 个逐秒切片，其中只有 5–8 个带 move 字段，其余只写动作
编译出来是「0–1s, 动作。1–2s, 动作。」的连续时间轴
```

`compile_prompts.py` 的 `beats_line()` 支持：`move` 留空就不输出运镜句，
`size` 跟着不输出（景别是运镜的落点，镜头不动时写景别会跟关键帧抢构图）。

段级运镜要写成**同一条运动的延续**，不是新动作：

```
✗  the camera whips left
✓  the same unbroken flight now carries the camera left and around the pair
```

### 机位什么时候可以停

战斗戏机位停下等于节奏断掉。只有三种情况该停：

```
片子结束
要表达某件特殊的事（例如插入镜里害怕的人，用手持微晃替他抖）
特殊技能的蓄力 —— 但更好的做法是机位继续动、人物定住
```

**「预备段静止」指的是人物身体定住**（蓄力那一拍只有布料和发梢在动），
不是机位停下。**机位在动 + 人物定住 = 最强反差**；两边都停是死画面，
两边都动是糊画面。

## 五、每个时间切片必须有身体动词

写状态会得到静止画面。`compile_prompts.py` 有门禁，`scan_body_verbs()` 逐片扫描。

```
✗  从光柱背面走出，剑上带着火星流，身后弹坑还在发亮   （三句全是状态）
✓  他大步走出光柱、反手把剑抡到低位架起、剑尖犁地拉出火星
```

**特效在动不算人在动。** 主语是「光/纹/层」的拍子要补一个人的动作：

```
✗  三道光柱自上砸落
✓  她抡杖过顶起阵 → 三道光柱砸落 → 他侧身起跑
```

## 六、特效必须做资产

**参考图锁得住外观，文字锁不住。** 出现 ≥2 次的特效都要立资产
（跟道具同一条判据）。没有资产锁住形态，资源读数这类设计等于没写。

特效资产比人物资产多三条要求：

```
透明背景 RGBA    要叠在画面上，白底会带一圈方块边。
                 模型给不了透明就出**纯黑底再抠** —— 发光特效的边缘过渡是加色的，
                 黑底抠出来的 alpha 更接近真实
颜色按阵营锁死    一方的特效串到另一方就乱套
画风跟角色一致    角色是赛璐璐，特效渲成写实光效叠上去就是两个世界
```

### 炸裂三层

写「爆开」出不来爆炸。**每一次命中都按三层写**：

```
核心   过曝的白热核（几乎纯白）
中层   饱和的本色
外圈   冲击波环 + 向外飞散的碎片光屑火星，带速度线
```

颜色拉到高饱和 + 白热核（`炽红→橙金` / `电蓝→青白`），
暗调特效在夜景里出不来对比。

### 范围写参照物，不写「巨大」

```
✗  巨大的剑气          ✓  新月弧宽横跨整个大殿，高过石柱，边缘削断两侧柱子
✗  强力的光矛          ✓  粗如石柱，尾焰拖满画面
✗  大范围法阵          ✓  单个六边形铺满整个地面，三个叠起来盖满全殿
```

## 七、形态切换要进资产，不能当形容词

写一句「他狂化了」等于没有。**分档递进，每档换资产、每档有可见代价、
每档给一个转变时刻**：

```
常态  0–10s   基准特征
H1   10–21s   一档变化   ← 第 10 秒推特写给这个转变
H2   21–30s   二档变化
```

### 派生形态必须从母板 edit，脸不动

各画各的会让三档看起来是三个人 —— 形态切换的戏剧效果全靠「同一个人变了」。

做法：以母板为**唯一输入图**走 edit，prompt 里逐条重申
「脸、发色、发型、盔甲、武器全部保持原图」，只改设定列出的那几样。
出完并排放大对脸（眉形、鼻梁、下颌、发际线），不是同一个人就重做。

## 八、prompt 的几条

**台词写进 prompt 会被烧成画面字幕**（动漫风格尤其）。取舍：

```
写进 prompt    有人声、口型对得上，但可能被烧字幕
移出 prompt    音轨只有打斗声，字幕后期挂 —— 打戏优先选这个
```

「不许出现文字」要写成正面表述：`The picture stays clear of printed words`。

**身份约束在长片里会被稀释。** 身份句要**每段重申一遍**，不是开头说一次；
并且用 ref2v 把全套资产当参考图喂进去。

**武器对武器、武器对护盾比人对人稳。** 远近对抗的打法天然满足这条。

## 九、渲染端

| | Seedance 2.0 | Seedance 2.5 |
|---|---|---|
| 参考图 / 跨模态总数 | 9 / 12 | 30 / 50 |
| 时长 | 4–15s | 4–30s |
| 分辨率 | 480p / 720p | 480p / 720p / 1080p |
| 写实真人参考图 | 收 | **拒**（内容策略，文档未写） |
| 动漫角色参考图 | 收 | 收 |
| 含人的参考视频 | 收 | **拒** |

```
长片一致性走 ref2v，不走 i2v      i2v 只锚首帧，切一次镜就换一张脸
第一版一律 480p                   大概率是废片，定稿了再上分辨率
修片走 2.0                        2.5 拒收含人视频
```
