# 立项规则：一部戏开拍前必须定死的东西

2026-08-17。

这是**创作基准**，不是流程文档。一部戏动手之前，下面每一条都要有答案，
而且答案要写成可指认的东西，不是形容词。

**每条规则标了来源档位**，照抄 chaoge 那套的做法，也是对我们自己的要求：

| 标 | 含义 |
|---|---|
| **[实测]** | 我们自己渲出来验证过的 |
| **[推断]** | 从实测规律推的，逻辑成立但没单独验过 |
| **[待验]** | 还不知道，先按这个走，第一部戏里验 |

分不清哪条是实测哪条是猜的，下一次就会在边界外被咬 ——
我们已经三次把一次观察推成普适结论（「参考图能控构图」、
「景别写死导致崩坏」、「一个否定词都不许写」），三次都错。

---

## 一、总原则：立项决定的不是风格，是资产量

**一部 100 集的戏做不做得下去，由资产复用率决定，不由题材决定。**

```
总资产量 ≈ 前 5 集建立的基础资产 + 每集新增 × 95
```

每个资产的真实成本（EP001 实测）：一张 char sheet 是一次 API 调用出 24 格，
但**改了三版才用第三版** —— v1 头发渲错、v2 定格格渲成证件照。
所以一个资产的成本是「生成 × 3 + 人工逐格审」，不是「一次调用」。

立项时最该问的一句话：**这部戏第 50 集要用的资产，第 5 集能不能就做完？**

答不上来就换题材。

---

## 二、视觉类型：写实真人 / 漫画 / 三维

这是第一个要定的，因为它决定后面所有判据的松紧。

| | 写实真人 | 漫画 / 动画 | 三维 |
|---|---|---|---|
| 一致性难点 | **脸** | **画风** | 建模，我们做不了 |
| 容错 | 极低 | 中 | — |
| 观众判据 | 拿真人衡量，差一点就恐怖谷 | 不拿真人衡量 | — |
| 我们的实测 | **[实测]** EP001 做的就是这个 | **[待验]** 没在我们链路上试过 | 不考虑 |

**[实测] 写实的脸靠 char sheet 锁得住。** EP001 的 24 格 sheet 逐格放大对脸
（眉形/眼距/鼻梁/下巴/唇形），24 格同一个人。方法是**一次生成 24 格**，
分开生成必漂。

**[推断] 漫画风的难点会从「脸」搬到「画风」。** 线条和色块对五官偏移容错高，
但画风漂（笔触粗细、上色方式、线稿轻重）比脸漂更显眼，而且画风没有
「参考图锁身份」那种硬控制面。

**规则：**

1. 定了就不许中途换。画风是全片级的，换一次前面全废。
2. 写实路线下，**脸是唯一的身份锚点，发式不是**。
   **[实测]** 把发式写进 `must_keep` 等于宣称这个人换衣服时头发不许变，
   模型会在两条硬约束之间自己挑一条违反，而挑哪条你控制不了。
3. 走漫画路线先做一集验证再定 100 集。**[待验]** 状态下不许排产。

## 三、题材：穿越 / 末世 / 无限流 / 都市 / 古装

**题材本身不是成本，「每集要新增多少资产」才是。**

| 题材 | 场景复用 | 服装复用 | 人物复用 | 100 集可行性 |
|---|---|---|---|---|
| **都市职场 / 校园** | 高（3–5 个场景撑全剧） | 高 | 高 | **最好** |
| **古装宅斗** | 中（府邸内几间房） | 中（品级决定服制） | 高 | 好 |
| **穿越** | 中 | **低**（现代 + 古代两套起） | 高 | 中 |
| **末世** | **低**（每集换地方） | 中（单一但要脏损状态） | 中 | 差 |
| **无限流** | **极低**（每个副本一套世界） | 低 | **极低**（每副本换人） | **最差** |

**[实测]** `搞笑办公室连续剧1` 全集只用 `LOC-OFFICE` 和 `LOC-OFFICE-DESKTOP`
两个场景资产，7 个道具。这就是高复用题材的样子。

**[实测]** 《回到古代当太子》全剧扫描出来：万花楼出现 54 次比太子府还高频，
「糖」只在 5 集出现但那 5 集里出现 41 次。**先读完全剧统计再做资产**，
只看一集做出来的到第二十集就要推倒重来。

**规则：**

1. **先扫全剧，统计每个场景/道具/角色出现多少次，再决定做哪些。**
   出现 ≥2 次才立资产，只出现一次的不立。
2. 高复用题材优先。要做末世或无限流，**必须先回答「怎么复用」** ——
   例如无限流把副本限制在 3 种世界观内循环。
3. 穿越题材的服装成本是双倍，立项时按两部戏的服装量估。

## 四、有没有动作戏 —— 这是最贵的一个决定

分两类，成本差一个数量级：

| | 非接触动作 | 接触动作 |
|---|---|---|
| 例 | 追逐、闪避、挥空、拔刀、摔门 | 扭打、抱、扶、拉扯、亲吻 |
| 难点 | 物理连贯性 | **两个人的身体要交叠** |
| 我们的判断 | **[推断]** 可做，必须切时间片 | **[推断]** 关键帧合不出来 |

**为什么接触动作难**：我们的关键帧是从**白底棚拍的单人 sheet 里裁格**
再合成的。两个人分开拍、分开裁，合成时姿态对不上 ——
「他抓住她的手腕」需要两只手在同一个空间坐标上，而两张参考图各自
是正面站立。**[实测]** 我们已经在单人镜上吃过近亲的亏：
写「他看向对方的脸」，模型手里只有一张参考图，要画那个对方就复制一份，
全剧 1143 镜中招。

**[实测] 静态对话镜有反向的坑**：首末帧几乎一样 → 模型「本该做的事」少
→ 它自己找事做（通常是造一扇门）。9.4 秒必填东西，缩到 6.6 秒一次通过。
**镜头越长越静，越危险。**

**规则：**

1. **动作戏必须切时间片**，一段一个独立的镜头目标：
   ```
   0–3s  全景，建立空间和双方位置
   3–6s  中景，冲突开启，谁先动
   6–10s 近景跟拍，细化肢体
   10–12s 拉远，收尾留张力
   ```
2. **写具象肢体动作，不写情绪。** **[实测]** 「凶狠」「冷静」这类词
   `compile_prompts.py` 会直接拦下 —— 在 EP001 现有 prompt 里抓到 4 处。
   写「抽刀向前突袭」「视线停在一处不动」。
3. **接触动作先做单镜验证再写进剧本。** 没验证过就不许在大纲里安排打戏。
4. 静态对话镜**宁可拆短**，不要为省钱拉长。

## 五、人物：数量、血缘、形态阶梯

**规则：**

1. **主要角色控制在 5 个以内。** 每多一个就多一张 sheet
   + 跨 100 集的一致性负担 + 同框时的克隆风险。
2. **有血缘关系的角色，必须先做父母再做子女。** **[推断，外部实测]**
   女儿的脸要从父母的脸派生，反过来做出来的不像一家人。
   狼人是男主的爸爸，外观就基于男主派生。
3. **会变的角色（变身/变老/受伤/异变），状态排成有序阶梯，
   全部从同一张人类母板派生。** 外部那套写死了一条：
   「所有异变阶段必须依赖同一人类母板」。状态进资产 ID
   （`CHR-LUCAS-MUTATION-H1`），不进 prompt。
4. **两人同框是克隆事故高发区。** **[实测]** 渲出过三个同脸角色并排穿龙袍。
   人数必须写死进 prompt（"The headcount is exactly 2"），
   四组受控对照里「写死人物+人数+地点」是唯一全面为正的改动
   （漂门 −18pp、人数错 −27pp、推焦 −36pp）。

### 人物卡要写什么

**[实测]** 我们的 `spec.md` 写法比外部那套硬，保持：
**写可指认的部件，不写抽象词。**

```
✗ 一支精致的细银簪          → 三次画成银球 / 宽刃剑 / 巨型簪
✓ 锥形细杆＋扁平五瓣梅花＋花心珍珠＋针尖＋杆长是花头宽的许多倍  → 一次就对

✗ 淡妆                      → 每次浓淡不同
✓ 细眼线、无浓密假睫毛、无成块腮红、无眼影色  → 三次出图稳定落在这一档
```

除了外形，还要写四样**随剧情变的**（这四样我们现在都没有）：

- **服装链**：角色级的时间线（冬季外套 → 脱去外套的衬衫 → …）
- **声音弧线**：不是一个静态音色（「由颤抖气音转为撕裂」）
- **反美颜指令**：「保留疲惫、低温和长途奔逃痕迹，不做无损妆面」
  —— 出图模型默认往精致里画
- **外在目标 / 内在恐惧**：动作从这里推，不从「这镜有没有人说话」推。
  **[实测]** 后者只有两三种状态，做多少变体都是换皮：
  修完台词泄漏之后全剧三分之一镜头变成同一个姿态，Top-1 占 34%。

## 六、场景：内景优先，先出骨架

**[实测]** 我们已知 Seedance 的 prompt **管不住三样**：空间关系
（说了「椅子在桌子对面」，它放在人身后同侧）、光位（参考图白天渲成夜景）、
桌面陈设（凭空多出一台笔记本电脑）。

**这三样只有图锁得住。** 所以：

**规则：**

1. **内景优先。** 可控、可复用、可拆骨架。外景的空间关系要一张带距离和
   方位的拓扑图才锁得住（外部那套标到米：段距 55/110/70/140，总距 375 米，
   带指北针和等高线）。
2. **先出无陈设的空间骨架，再派生各房间。** 外部的场景清单第 5 条就是
   「一层毛坯户型骨架」，它本身是资产，不是草稿。
3. **每个内景要一张平面图**：门、窗（决定光从哪来）、家具朝向、镜头轴线。
   没有它人物会在自己家里迷路。
4. **场景的光照状态进资产 ID**，不进 prompt。
   外部那套的清单里五条带 `·通电`（剧情是全屋断电后发电机恢复）。
   我们的对应物是「白天/夜晚/百叶窗半开」。
5. **多机位一次生成再切。** **[实测]** 我们的 char sheet 就是这么做的
   （24 格一次调用），场景现在没享受到这条待遇。
   正打/反打/过肩/俯视排进一张图一次出，切出来才不会漂。
6. **[实测] 近景一张场景图都不喂。** 近景背景本该完全虚化，
   喂全景只会跟「只有一张脸」打架。

## 七、服装：造型数是资产量的主要放大器

**[实测] 图赢 —— 想换造型必须换图，不能只换字。**
赵承全剧 565 镜穿常服，改了造型定义、改了 500 镜的 `uses.looks`、
prompt 里也拼进了「月白色圆领常服袍」，但绑给模型的参考图是
穿越前的现代灰 T 恤 —— 渲出来还是 T 恤，皇帝穿着现代黑衬衫。

**规则：**

1. **每个非基底造型必须有自己的参考图**，用 Edit 拿基底图换装生成，脸不动。
   `is_base=True` 的造型才共用基底图 —— 这个标记错一次，出图脚本会
   跳过不生成，而门禁会放行。
2. **造型总数 = 角色数 × 平均造型数**，这是立项时最该压的数字。
   主角 3 套、配角 1 套是合理起点。
3. **服装是独立资产**（同一件可能多人穿），但**造型必须跟着分镜走**：
   哪一镜穿哪套要写在分镜里。**[实测]** 渲染层一开始只带角色 id 不带 look，
   EP001 前九镜的寝衣散发被拼成了束发戴玉冠 —— 开场三秒就穿错衣服。
4. **状态（脏/破/湿/血）算造型的一档**，进资产 ID。
5. **[实测] 词不对模型不认。** 「束乌木銙带」渲成西式皮带扣，
   改成「同色织锦宽腰带，无金属扣、无皮革」就对了。
   写不出可指认部件的服装，先换个说法再立项。

## 八、光线与时间：时间轴是一串光线状态

**[推断，外部实测]** 时间轴不是时间戳。外部那套写的是：

> 主线约从 22:00 持续到次日 03:00，总跨度约 5 小时。光线依次经历：
> 雪林微弱月光与深黑树影 → 全屋断电、手电筒昏黄光柱 →
> 发电机恢复后的老旧电灯 → 壁炉形成的短暂暖光安全区 →
> 卧室近乎全黑的异变空间 → 大门开启时灌入的冷雪反光

每一格直接可渲染。

**规则：**

1. 一集之内的光线状态列出来，每一格要能画。
2. 一部戏定死全片的曝光基准（例：整体欠曝 0.7–1 档，
   高光以什么面不过曝为准），写进视觉基准。
3. **光影只在 prompt 的全局段说一次**，不在每个时间切片重复。

## 九、镜头语言：全片级锁死

**[推断，外部实测]** 外部那套把摄影系统锁到：机型、镜头家族、画幅、帧率、
快门角度，**并且每个焦段负责什么写死**（24–32mm 逃亡与搏斗、
40–50mm 家庭关系与日常观察、75mm 只用于心理节点）。

我们现在只有逐镜 `camera.size/angle/move`，没有全片级的分工，
所以镜头语言是逐镜随机的，不是一部片子。

**规则：**

1. 立项时定一张「景别分工表」：哪类戏用哪个景别，写死。
2. **[实测] 构图归关键帧管，prompt 不写景别。**
   出关键帧时物理取景必须写死（那一步没有参考构图，文字是唯一来源）；
   视频 prompt 里只写「中段别引入新东西」。**同一个字段，在链路的
   两端一个必须写、一个必须不写。**
3. **[实测] `extreme_close` 全剧删除。** 参考图控制不了构图 ——
   把角色参考图裁成头肩再喂进去，46%/40%/30% 三档控制变量测下来
   输出几乎没变化，始终是头到腰。写得越具体矛盾越致命：
   写「眉毛到下巴、肩膀不入画」之后模型认真了，5 秒里把人推没了，
   连性别都换了。

## 十、立项检查表

动手前逐条填，填不出来的不许开工：

```
□ 视觉类型          写实 / 漫画 / 其他，且已验证过一集
□ 题材              并回答「第 50 集的资产第 5 集能不能做完」
□ 全剧扫描统计      场景/道具/角色各出现多少次，≥2 次才立资产
□ 主要角色数        ≤5，血缘关系标出来（谁必须先做）
□ 形态阶梯          有变身/变老/受伤的角色，阶段排序
□ 动作戏            有无接触动作；有的话先做单镜验证
□ 场景清单          内景外景分开；每个内景要平面图
□ 场景状态          光照/时段版本列出来
□ 造型总数          角色数 × 平均造型数，主角 3 套配角 1 套起
□ 服装可指认        每套能不能写出部件，写不出先换说法
□ 光线时间轴        一集之内的光线状态，每格要能画
□ 曝光基准          全片欠曝档位 + 高光以什么不过曝为准
□ 景别分工表        哪类戏用哪个景别
□ 情绪曲线          幕结构 + 拍点数值 + 包袱落点 + 呼吸区
```

**最后一条最容易跳过，也最贵。** 没有情绪曲线就没法回答
「这一集为什么不好看」—— 只能靠人看完凭感觉说。

## 十一、这份规则本身的边界

标 **[待验]** 的条目在第一部戏里必须验掉，验完回来改这份文档并升级标签。

**规律要带着它的适用边界一起记，否则下一次它就在边界外咬你。**
